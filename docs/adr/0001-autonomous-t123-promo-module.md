# 0001. Автономный T123-модуль для октябрьских акций на Tilda

## Контекст и проблема
Клинике «Катрин» необходимо опубликовать 5 взаимосвязанных коммерческих предложений на октябрь 2026 года на страницах `https://catherine-salon.ru/` (первый блок под шапкой) и `https://catherine-salon.ru/uslugi` (над каталогом услуг). Страницы сайта в Tilda собраны на жестких Zero-блоках (`t396`) с фиксированными абсолютными координатами под 5 экранов. Прямая модификация текстов внутри Zero-блоков или инъекция нестандартных элементов ломает мобильную адаптивность и усложняет ежемесячную сменяемость акций.

## Принятое решение
Разработать единый изолированный компонент для блока Tilda T123 («HTML-код») `october-promos-t123.html`:
1. Включает якорную точку `#promos` для бесшовной интеграции с меню навигации страницы `/uslugi`.
2. Содержит акцентный графический баннер краткосрочного флеш-события («День красоты 30–31 октября») и адаптивную сетку 4 регулярных предложений месяца («Первое знакомство», «PicoSure», «Fotona 4D», «Рекомендуй Катрин»).
3. Выдержан в фирменной строгой геометрии клиники (`border-radius: 0`, палитра `#171717` / `#ffffff`, шрифтовая пара `Forum` + `Montserrat`).
4. Интегрирован со штатной системой заявок Tilda через триггер `#popup:zayavka` (блок `rec608825704` / форма `#form608825704`) с автоматической подстановкой выбранной акции в подзаголовок попапа и скрытое поле `promo_name`.
5. Оснащен встроенной автономной формой записи (Fallback Modal), которая бесшовно открывается при локальном тестировании или если скрипт Тильды не ответил на вызов.

## Последствия
- **Плюсы**: Идентичный код вставляется в обе страницы в один клик; нулевой риск сломать существующие Zero-блоки; полная совместимость со штатным попапом `#popup:zayavka` клиники; гарантированное открытие формы даже при сбоях внешних скриптов.
- **Компромиссы**: Редактирование текстов акций при необходимости проводится через исходный HTML-код компонента, а не через визуальный редактор Zero Block.
