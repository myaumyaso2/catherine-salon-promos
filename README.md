## 🎯 Архитектура

Все промо-блоки встроены напрямую в стандартные блоки T123:
- **Главная страница**: `pageid: 36313283`, блок T123 `record4607406401`
- **Страница «Услуги»**: `pageid: 36317049`, блок T123 `record4607617701`

### Преимущества прямой работы через Tilda MCP:
1. **100% SEO-оптимизация**: Весь текст акций (заголовки H2/H3, цены, ключевые фразы Morpheus 8, PDRN) отдается напрямую веб-сервером Тильды в статическом HTML и мгновенно индексируется Яндексом и Google без выполнения JS.
2. **Нулевая зависимость от сторонних CDN**: Все медиафайлы хранятся на официальном CDN Тильды (`static.tildacdn.com`), код хранится в базе Тильды.
3. **Полная автоматизация**: Агент загружает изображения, обновляет код блоков и публикует страницы за 5 секунд через официальные инструменты:
   - `upload_image` — загрузка картинок на Tilda CDN
   - `update_record` — сохранение разметки в блоки T123
   - `publish_page` — публикация страниц

## 📋 Регламент ежемесячного обновления (Инструкция)

При получении нового документа с акциями (например, на декабрь):

1. **Генерация баннеров**:
   - Агент генерирует баннеры 16:9 в фирменном стиле (темный градиент, премиальная эстетика, без текста).
   - Вызывает `upload_image` в Tilda MCP ➔ получает прямые ссылки на CDN Тильды.

2. **Формирование разметки**:
   - Обновляет текстовые офферы, даты, цены и модальные окна регламентов в компоненте.

3. **Сохранение и публикация**:
   - Вызывает `update_record` для `record4607406401` (Главная) и `record4607617701` (Услуги).
   - Вызывает `publish_page` для страниц `36313283` и `36317049`.

**Весь процесс занимает менее минуты прямо в диалоге с агентом.**
