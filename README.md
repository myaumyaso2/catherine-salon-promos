# Управление сайтом catherine-salon.ru на Tilda через Antigravity

## 1. Есть ли способ эффективно управлять сайтом на Tilda через Antigravity?

**Да, и наиболее эффективный путь — гибридный подход «генератор компонентов для T123».**

### Почему стандартное API Тильды не подходит для прямого управления страницами?
* У Tilda **нет публичного REST API на запись произвольных блоков страниц** (официальное API Tilda Business только отдает список страниц и HTML/CSS для внешнего хостинга).
* На `catherine-salon.ru` страницы (например, `/price`) состоят из **47 жестких Zero Block (`t396`)**. У каждого элемента координаты зафиксированы под 5 экранов (320, 480, 640, 960, 1200 px). Если попытаться менять текст скриптом или браузерным ботом в Zero Block, блоки расползаются, а верстка на смартфонах ломается.

### 3 проверенные стратегии управления сайтом через Antigravity:

| № | Стратегия | Как работает | Когда применять |
|---|---|---|---|
| **1 (Рекомендуемая)** | **Генератор автономных блоков T123 («HTML-код»)** | Antigravity хранит структурированные данные (JSON, списки цен, тексты акций, виджеты), генерирует чистый семантический HTML/CSS/JS, а вы или агент вставляете его в блок T123. | Интерактивные виджеты, опросники, отзывы, калькуляторы, обновляемые прайс-листы с поиском и табами. |
| **2** | **Внешняя динамическая база данных (Headless)** | Данные (прайс, мастера, акции) лежат в JSON/GitHub или Google Таблицах. В Tilda один раз ставится скрипт-загрузчик, который подтягивает актуальные данные без захода в админку. | Еженедельное обновление цен, быстрое отключение неактивных акций. |
| **3** | **Браузерная автоматизация (Playwright / Chrome DevTools MCP)** | Antigravity открывает `tilda.cc`, авторизуется по кукам, переходит в нужные разделы (Каталог, Потоки, настройки страниц) и нажимает кнопки публикации. | Публикация готовых страниц, пакетная заливка товаров/новостей. |

## 3. На какую почту уходят сообщения и как настроить доставку на 2 адреса в Tilda:

Целевые адреса для получения оценок:
* **`katrin.klinik@mail.ru`**
* **`salon.catherinenn@yandex.ru`**

### Пошаговая настройка в Tilda (за 2 минуты):

1. **В панели Tilda перейдите**:  
   `Настройки сайта` → вкладка `Формы` → блок `Email`.
2. **Укажите email-адреса**:  
   * Можно указать оба адреса через запятую: `katrin.klinik@mail.ru, salon.catherinenn@yandex.ru`  
   * Либо добавить два отдельных подключения типа «Email» (одно на Mail.ru, второе на Yandex.ru).
3. **Подтвердите подключение**:  
   На оба ящика придут письма от Tilda со ссылкой для подтверждения. Нажмите на них.
4. **На странице с виджетом** (например, `/visit-feedback`):
   * Добавьте блок T123 с кодом виджета [`feedback-widget-t123.html`](file:///c:/Users/trash/Documents/antigravity/catherine-salon.ru/components/feedback-widget/feedback-widget-t123.html).
   * Ниже добавьте стандартный блок формы Tilda (например, **BF204N**).
   * В «Контенте» формы поставьте галочки напротив подключенных Email (`katrin.klinik@mail.ru` и `salon.catherinenn@yandex.ru`).
   * В «Настройках» блока формы укажите класс: `cf-tilda-form`, и спрячьте блок (или задайте видимость 0, либо виджет сам скроет его и вызовет в фоновом режиме).
5. **Нажмите «Опубликовать»**.
