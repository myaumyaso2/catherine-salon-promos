# 🌸 Catherine Salon — Модуль спецпредложений (Zero-Tilda)

Автономный динамический модуль ежемесячных специальных предложений клиники врачебной и эстетической косметологии **«Катрин»** ([catherine-salon.ru](https://catherine-salon.ru/)).

---

## 🎯 Архитектура Zero-Tilda

Вместо ручного входа в редактор Тильды, копирования тяжелого 38 КБ кода и перепубликации страниц, блоки T123 на страницах настраиваются на **тонкий загрузчик (лоадер)**. 

Лоадер асинхронно монтирует актуальный бандл из глобального CDN:
- **CDN**: `https://cdn.jsdelivr.net/gh/myaumyaso2/catherine-salon-promos@main/dist/promos.min.js`
- **Резервный CDN**: `https://myaumyaso2.github.io/catherine-salon-promos/dist/promos.min.js`

Все будущие обновления акций (в декабре, январе и т.д.) применяются **за 30 секунд через обычный коммит в репозиторий**, без необходимости заходить в Тильду!

---

## 📋 Как обновлять акции каждый месяц (Инструкция)

### Шаг 1: Изменить данные акций
Откройте файл [`src/data/promosData.js`](./src/data/promosData.js) и внесите изменения:
- Месяц и даты (например, «Декабрь 2026», `01—31 декабря 2026`).
- Оффер главного Hero-баннера (Morpheus 8 или другой флагман).
- Сетку из 3 программ месяца (PDRN, консультация, лояльность).
- Регламенты и тексты модальных окон условий.

### Шаг 2: Собрать оптимизированный бандл
В терминале выполните:
```bash
npm run build
```
Скрипт автоматически соберет свежий бандл `dist/promos.min.js` с инлайн-стилями, версткой и интерактивностью.

### Шаг 3: Опубликовать через Git
```bash
git add .
git commit -m "feat: акции на декабрь 2026 года"
git push
```
**Всё!** Через 1–2 минуты CDN подхватит обновление, и новые акции автоматически появятся на Главной странице и странице Услуг.

## 🧩 Код лоадера для блока T123 в Тильде

Этот код размещается в блоке T123 клиники один раз:

```html
<!-- ========================================================
     КЛИНИКА «КАТРИН» — ДИНАМИЧЕСКИЙ БЛОК АКЦИЙ (ZERO-TILDA)
     Данный блок размещается в T123 один раз.
     Все акции подгружаются автоматически из CDN репозитория.
     ======================================================== -->
<div id="catherine-promos-container"></div>
<script>
  (function() {
    var s = document.createElement('script');
    s.async = true;
    var v = new Date().toISOString().slice(0, 13).replace(/[-T]/g, '');
    s.src = 'https://cdn.jsdelivr.net/gh/myaumyaso2/catherine-salon-promos@main/dist/promos.min.js?v=' + v;
    s.onerror = function() {
      var f = document.createElement('script');
      f.async = true;
      f.src = 'https://myaumyaso2.github.io/catherine-salon-promos/dist/promos.min.js?v=' + v;
      document.head.appendChild(f);
    };
    document.head.appendChild(s);
  })();
</script>
```

## 🎨 Фирменный стиль клиники
- **Шрифты**: `Forum` (заголовки), `Montserrat` (текст и списки).
- **Палитра**: Графит (`#171717`), благородное золото (`#c5a265`, hover `#b08d51`), фоны карточек (`#ffffff`, `#fcfcfc`).
- **Геометрия**: `border-radius: 0px` (строгая премиальная архитектура).
- **Интеграция с записью**: кнопки «Записаться...» автоматически открывают официальный поп-ап Тильды `#popup:zayavka` (`rec608825704`) и передают точное название выбранного спецпредложения в поле `promo_name`.
